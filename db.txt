Panduan Lengkap Mengatur Database Supabase untuk Aplikasi CBTSupabase adalah layanan database berbasis awan (cloud) yang sangat handal dan gratis. Untuk membangun ulang database aplikasi CBT Anda dari awal secara bersih dan tanpa kesalahan, Anda dapat menggunakan metode otomatis menggunakan Kode SQL Instan yang sangat praktis dan cepat.Aplikasi CBT kita membutuhkan 3 Tabel Utama:BankSoal: Tempat menyimpan data soal, gambar, opsi pilihan (A-D), dan kunci jawaban.DataNilai: Tempat menampung hasil ujian siswa, skor, deteksi kecurangan, dan analisis kesukaran soal.AdminAuth: Tempat menyimpan kredensial (Username & Password) untuk Admin biasa secara online, sehingga bisa diubah dan direset secara dinamis oleh Super Admin.LANGKAH 1: Mendaftar dan Membuat Project BaruBuka situs resmi Supabase di https://supabase.com.Klik tombol "Start your project" di pojok kanan atas (Anda bisa mendaftar gratis menggunakan akun GitHub atau Email Anda).Setelah masuk ke Dasbor utama, klik tombol hijau "New Project".Isi detail proyek baru Anda dengan teliti:Organization: Pilih organisasi Anda (biasanya nama akun Anda).Name: Tulis CBT-SMPN3 (atau nama sekolah/ujian Anda).Database Password: Klik Generate a password atau buat kata sandi yang kuat. Penting: Catat dan simpan kata sandi ini baik-baik!Region: Sangat disarankan memilih Singapore agar kecepatan akses data siswa dari Indonesia menjadi sangat kilat dan minim delay.Pricing Plan: Pilih paket Free ($0/month) yang sudah lebih dari cukup untuk menampung ribuan siswa.Klik "Create new project" dan tunggu sekitar 2 menit hingga Supabase selesai merakit server database Anda.LANGKAH 2: Mengambil API Key dan URL ProyekAgar aplikasi CBT (file HTML Anda) dapat mengirim nilai siswa, menarik soal, serta mengecek password admin secara otomatis dari Supabase, Anda harus menghubungkannya menggunakan alamat URL dan Kunci Akses unik Anda.Di panel navigasi sebelah kiri layar Supabase Anda, cari dan klik ikon ⚙️ Project Settings (ikon gir di paling bawah).Pilih menu API yang berada di bawah kategori Configuration.Pada halaman ini, salin informasi penting berikut:Project URL: Berformat seperti https://xxxxxx.supabase.coProject API Keys (anon / public): Berupa deretan teks acak yang panjang.Buka file cbt-app.html Anda menggunakan aplikasi teks editor, cari baris di sekitar baris ke-450, dan perbarui isinya:// ===========================================================================
// KONFIGURASI SUPABASE (Masukkan kredensial Supabase Anda di sini)
// ===========================================================================
const SUPABASE_URL = "[https://xxxxxx.supabase.co](https://xxxxxx.supabase.co)"; // TEMPELKAN URL ANDA DI SINI
const SUPABASE_ANON_KEY = "eyJhbGciOiJIUzI1..."; // TEMPELKAN ANON KEY ANDA DI SINI
// ===========================================================================
LANGKAH 3: Membuat Database Secara Otomatis (Rekomendasi)Ini adalah cara paling profesional, aman, dan instan. Kita akan menggunakan fitur SQL Editor untuk membuat tabel BankSoal, DataNilai, dan AdminAuth sekaligus hanya dengan sekali klik run.Di menu navigasi sebelah kiri Supabase Anda, cari dan klik ikon SQL Editor (ikon berbentuk terminal dengan simbol SQL atau jalankan pintasan keyboard).Klik tombol "+ New Query" atau klik "Create a new query" untuk membuka halaman lembar kerja SQL kosong.Salin (copy) seluruh blok kode SQL di bawah ini secara utuh:-- 1. HAPUS TABEL JIKA SEBELUMNYA SUDAH PERNAH ADA (UNTUK RESET BERSIH)
DROP TABLE IF EXISTS "BankSoal";
DROP TABLE IF EXISTS "DataNilai";
DROP TABLE IF EXISTS "AdminAuth";

-- 2. MEMBUAT TABEL BANK SOAL SECARA PRESISI
CREATE TABLE "BankSoal" (
  "No" INT8 PRIMARY KEY,
  "Soal" TEXT NOT NULL,
  "URL Gambar Soal" TEXT NULL,
  "Opsi A" TEXT NOT NULL,
  "Gambar Opsi A" TEXT NULL,
  "Opsi B" TEXT NOT NULL,
  "Gambar Opsi B" TEXT NULL,
  "Opsi C" TEXT NULL,
  "Gambar Opsi C" TEXT NULL,
  "Opsi D" TEXT NULL,
  "Gambar Opsi D" TEXT NULL,
  "Kunci Jawaban" TEXT NOT NULL
);

-- 3. MEMBUAT TABEL DATA NILAI SISWA SECARA PRESISI
CREATE TABLE "DataNilai" (
  "id" INT8 GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  "Waktu Submit" TEXT NOT NULL,
  "Nama Siswa" TEXT NOT NULL,
  "Kelas" TEXT NOT NULL,
  "Skor Benar" INT4 NOT NULL,
  "Total Soal" INT4 NOT NULL,
  "Nilai Akhir (100)" NUMERIC NOT NULL,
  "Status Kecurangan" TEXT NOT NULL DEFAULT 'Aman',
  "Detail Jawaban" TEXT NULL
);

-- 4. MEMBUAT TABEL KEAMANAN LOGIN ADMIN DI DATABASE
CREATE TABLE "AdminAuth" (
  "id" INT8 PRIMARY KEY DEFAULT 1, -- Selalu 1 agar hanya ada 1 baris pengaturan admin
  "Username" TEXT NOT NULL DEFAULT 'admin',
  "Password" TEXT NOT NULL DEFAULT 'adminspentig'
);

-- 5. MEMASUKKAN DATA DEFAULT AWAL UNTUK ADMIN (AUTO-SEED)
INSERT INTO "AdminAuth" ("id", "Username", "Password") 
VALUES (1, 'admin', 'adminspentig')
ON CONFLICT ("id") DO NOTHING;

-- 6. MENONAKTIFKAN ROW LEVEL SECURITY (RLS) AGAR JAVASCRIPT HTML BISA TERHUBUNG LANGSUNG
ALTER TABLE "BankSoal" DISABLE ROW LEVEL SECURITY;
ALTER TABLE "DataNilai" DISABLE ROW LEVEL SECURITY;
ALTER TABLE "AdminAuth" DISABLE ROW LEVEL SECURITY;
Tempel (paste) kode SQL di atas ke dalam lembar kerja SQL Editor yang kosong di Supabase.Klik tombol hijau "Run" di bagian kanan bawah area kerja SQL Editor.Periksa kotak output di bawahnya. Jika tertulis "Success. No rows returned", maka database Anda telah selesai dikonfigurasi secara sempurna!LANGKAH 4: Memastikan Kunci Keamanan (RLS) DinonaktifkanSeringkali Supabase secara otomatis mengaktifkan fitur keamanan tambahan (Row Level Security / RLS) demi melindungi database proyek. Namun karena aplikasi CBT kita berjalan secara mandiri (client-side Javascript), RLS wajib dinonaktifkan agar sistem dapat diakses secara langsung.Mari pastikan sekali lagi:Di panel navigasi sebelah kiri, klik ikon gembok 🔐 Authentication.Pilih menu Policies (terletak di bilah atas atau bilah samping).Di halaman kebijakan ini, pastikan pada kartu tabel BankSoal, DataNilai, dan AdminAuth terdapat indikator berwarna abu-abu/hijau dengan tulisan "RLS disabled" (RLS dinonaktifkan).Jika indikator menunjukkan "RLS enabled", segera klik tombol "Disable RLS" di pojok kanan atas tabel tersebut untuk menonaktifkannya secara permanen.
