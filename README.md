# CBT-NYM-DEV
Panduan Lengkap Mengatur Database Supabase untuk Aplikasi CBTSupabase adalah layanan database berbasis awan (cloud) yang sangat handal dan gratis. Untuk membangun ulang database aplikasi CBT Anda dari awal secara bersih dan tanpa kesalahan, Anda dapat menggunakan metode otomatis menggunakan Kode SQL Instan yang sangat praktis dan cepat.Aplikasi CBT kita membutuhkan 2 Tabel Utama:BankSoal: Tempat menyimpan data soal, gambar, opsi pilihan (A-D), dan kunci jawaban.DataNilai: Tempat menampung hasil ujian siswa, skor, deteksi kecurangan, dan analisis kesukaran soal.LANGKAH 1: Mendaftar dan Membuat Project BaruBuka situs resmi Supabase di https://supabase.com.Klik tombol "Start your project" di pojok kanan atas (Anda bisa mendaftar gratis menggunakan akun GitHub atau Email Anda).Setelah masuk ke Dasbor utama, klik tombol hijau "New Project".Isi detail proyek baru Anda dengan teliti:Organization: Pilih organisasi Anda (biasanya nama akun Anda).Name: Tulis CBT-SMPN3 (atau nama sekolah/ujian Anda).Database Password: Klik Generate a password atau buat kata sandi yang kuat. Penting: Catat dan simpan kata sandi ini baik-baik!Region: Sangat disarankan memilih Singapore agar kecepatan akses data siswa dari Indonesia menjadi sangat kilat dan minim delay.Pricing Plan: Pilih paket Free ($0/month) yang sudah lebih dari cukup untuk menampung ribuan siswa.Klik "Create new project" dan tunggu sekitar 2 menit hingga Supabase selesai merakit server database Anda.LANGKAH 2: Mengambil API Key dan URL ProyekAgar aplikasi CBT (file HTML Anda) dapat mengirim nilai siswa dan menarik soal secara otomatis dari Supabase, Anda harus menghubungkannya menggunakan alamat URL dan Kunci Akses unik Anda.Di panel navigasi sebelah kiri layar Supabase Anda, cari dan klik ikon ⚙️ Project Settings (ikon gir di paling bawah).Pilih menu API yang berada di bawah kategori Configuration.Pada halaman ini, salin informasi penting berikut:Project URL: Berformat seperti https://xxxxxx.supabase.coProject API Keys (anon / public): Berupa deretan teks acak yang panjang.Buka file cbt-app.html Anda menggunakan aplikasi teks editor (seperti Notepad, VS Code, atau sejenisnya), cari baris di sekitar baris ke-400, dan perbarui isinya:// ===========================================================================

LANGKAH 3: Membuat Database Secara Otomatis (Rekomendasi)Ini adalah cara paling profesional dan instan. Kita akan menggunakan fitur SQL Editor untuk membuat tabel BankSoal dan DataNilai sekaligus hanya dengan sekali klik run.Di menu navigasi sebelah kiri Supabase Anda, cari dan klik ikon SQL Editor (ikon berbentuk terminal dengan simbol SQL atau jalankan pintasan keyboard).Klik tombol "+ New Query" atau klik "Create a new query" untuk membuka halaman lembar kerja SQL kosong.Salin (copy) seluruh blok kode SQL di bawah ini secara utuh:-- 1. HAPUS TABEL JIKA SEBELUMNYA SUDAH PERNAH ADA (UNTUK RESET BERSIH)
DROP TABLE IF EXISTS "BankSoal";
DROP TABLE IF EXISTS "DataNilai";

-- 2. MEMBUAT TABEL BANK SOAL SECARA PRESISI
CREATE TABLE "BankSoal" (
  "No" INT8 PRIMARY KEY,
  "Soal" TEXT NOT NULL,
  "URL Gambar Soal" TEXT NULL,
  "Opsi A" TEXT NOT NULL,
  "Gambar Opsi A" TEXT NULL,
  "Opsi B" TEXT NOT NULL,
  "Gambar Opsi B" TEXT NULL,
  "Opsi C" TEXT NULL,
  "Gambar Opsi C" TEXT NULL,
  "Opsi D" TEXT NULL,
  "Gambar Opsi D" TEXT NULL,
  "Kunci Jawaban" TEXT NOT NULL
);

-- 3. MEMBUAT TABEL DATA NILAI SISWA SECARA PRESISI
CREATE TABLE "DataNilai" (
  "id" INT8 GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  "Waktu Submit" TEXT NOT NULL,
  "Nama Siswa" TEXT NOT NULL,
  "Kelas" TEXT NOT NULL,
  "Skor Benar" INT4 NOT NULL,
  "Total Soal" INT4 NOT NULL,
  "Nilai Akhir (100)" NUMERIC NOT NULL,
  "Status Kecurangan" TEXT NOT NULL DEFAULT 'Aman',
  "Detail Jawaban" TEXT NULL
);

-- 4. MENONAKTIFKAN ROW LEVEL SECURITY (RLS) AGAR JAVASCRIPT HTML BISA TERHUBUNG LANGSUNG
ALTER TABLE "BankSoal" DISABLE ROW LEVEL SECURITY;
ALTER TABLE "DataNilai" DISABLE ROW LEVEL SECURITY;
Tempel (paste) kode SQL di atas ke dalam lembar kerja SQL Editor yang kosong di Supabase.Klik tombol hijau "Run" di bagian kanan bawah area kerja SQL Editor.Periksa kotak output di bawahnya. Jika tertulis "Success. No rows returned", maka Tabel BankSoal dan DataNilai Anda telah sukses terbangun 100% sempurna dengan tipe data yang sangat presisi!LANGKAH 4: Metode Alternatif - Membuat Tabel Secara ManualJika Anda lebih menyukai membuat tabel satu per satu secara visual menggunakan antarmuka grafis di Supabase, Anda dapat mengikuti panduan manual ini:A. Namun karena aplikasi CBT kita berjalan secara mandiri (client-side Javascript), RLS wajib dinonaktifkan agar siswa dapat langsung membaca bank soal dan mengirim nilai mereka secara anonim tanpa perlu mendaftar akun email di Supabase.Mari pastikan sekali lagi:Di panel navigasi sebelah kiri, klik ikon gembok 🔐 Authentication.Pilih menu Policies (terletak di bilah atas atau bilah samping).Di halaman kebijakan ini, pastikan pada kartu tabel BankSoal dan DataNilai terdapat indikator berwarna abu-abu/hijau dengan tulisan "RLS disabled" (RLS dinonaktifkan).Jika indikator menunjukkan "RLS enabled", segera klik tombol "Disable RLS" di pojok kanan atas tabel tersebut untuk menonaktifkannya secara permanen.LANGKAH 6: Menguji Koneksi dan Mengisi Soal PertamaSelamat! Database backend CBT Anda sekarang sudah beroperasi penuh. Mari kita uji coba pengisian data pertamanya:Buka file aplikasi CBT Anda (cbt-app.html) di browser laptop.Di halaman masuk utama, klik tombol abu-abu di bagian bawah: "LOGIN ADMIN".Masukkan kredensial default admin:Username: adminPassword: adminspentigTekan Enter atau klik "MASUK ADMIN" untuk masuk ke Dashboard CBT Administrator.Anda akan langsung berada di tab Kelola Bank Soal. Klik tombol biru "+ TAMBAH SOAL".Isi formulir dengan soal matematika Anda (gunakan bilah toolbar matematika untuk menyisipkan rumus eksak/simbol secara mudah).Klik "Simpan Data". Jika berhasil, soal akan langsung muncul di baris tabel kelola bank soal dan itu tandanya Supabase Anda telah terhubung secara sempurna dan siap melaksanakan ujian!
